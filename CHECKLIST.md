# Проверка перед публикацией

Автоматические проверки прошли. Этот список ещё нужно выполнить в настоящем браузере: доступ к браузерному просмотру в сессии создания был отклонён.

- На ширине 360/390/768/1440 px нет горизонтальной прокрутки; текст и кнопки видны, обложки читаемы.
- Свайп влево переносит книгу в «Отложенное», возврат восстанавливает её в знакомствах. Вертикальная прокрутка не вызывает случайный выбор.
- Свайп вправо открывает аннотацию; закрытие не добавляет книгу, кнопка добавления сохраняет «Хочу прочитать».
- Все четыре статуса сохраняются после перезагрузки; поиск и фильтр библиотеки работают.
- Отмена возвращает последний выбор. Смена статуса тоже отменяется в рамках сеанса.
- Связи Алисы и Мира-Кольца открывают нужную карточку, не добавляя её автоматически.
- Статистика и цель меняются после статусов, отмены и импорта.
- Экспортировать → изменить библиотеку → импортировать: состояние восстанавливается после подтверждения. Повреждённый JSON не меняет данные.
- При запрете `localStorage` появляется понятное сообщение, изменение не объявляется сохранённым.
- После полного первого открытия закрыть вкладку, отключить сеть, открыть приложение снова: интерфейс и каталог доступны; просмотренные обложки берутся из кэша, остальные показывают заглушку.
- Tab, Enter, стрелки и Escape работают; диалог удерживает фокус, закрытие возвращает его. Уменьшение анимации учитывается.
- На GitHub Pages приложение работает в подпапке репозитория; из внешних запросов загружаются только обложки с CDN издателей; библиотека и решения не отправляются.
- При обновлении кэша старая библиотека остаётся, новые ресурсы появляются после закрытия старых вкладок.

- Переключить три темы, перезагрузить и восстановить резервную копию: выбор сохраняется. В ночной теме нет светлых панелей или нечитаемого текста.
- Просмотреть 20 карточек, обновить страницу, сменить жанр и отменить решение: двадцать первая новая карточка не выдаётся.
- Проверить обновление подборки после локальной полуночи, в том числе после возврата в оставленную открытой вкладку.
- Заблокировать изображение обложки: появляется заглушка, кнопки выбора остаются доступны.
