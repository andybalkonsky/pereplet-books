# Переплёт — книжные знакомства

Русскоязычное браузерное приложение: выберите книгу по первому впечатлению и соберите собственную библиотеку. Отдельный проект, вдохновлённый простотой [Kotoba](https://github.com/andybalkonsky/kotoba-japanese-trainer) и [Sakura](https://github.com/andybalkonsky/sakura-kanji-n5). Их код и данные не изменялись.

## Как пользоваться

- **Открывать:** карточка показывает графическую обложку, название, автора и жанр. Жанр можно изменить над карточкой.
- **Свайп влево / «Не сейчас»:** книга отправляется в отдельный архив «Отложенное».
- **Свайп вправо / «Интересно»:** открывается короткая аннотация без сюжетных поворотов. Нажмите «Добавить в “Хочу прочитать”», чтобы сохранить книгу. Закрытие карточки без добавления оставляет её в знакомствах.
- **↶:** отменяет последний выбор или смену статуса в текущем сеансе. История отмены не переносится через перезагрузку и импорт.
- **Библиотека:** все принятые книги, поиск по названию, автору и жанру, фильтр и смена статуса: «Хочу прочитать», «Читаю», «Прочитано», «Брошено».
- **Отложенное:** просмотр отклонённых книг и возврат в знакомства. Из карточки можно сразу добавить книгу в библиотеку.
- **Связанные книги:** открываются внутри карточки; связь подписана как продолжение, начало или рекомендация. Переход сам по себе не добавляет книгу.
- **Статистика:** текущие статусы, число решений, жанры библиотеки и личная цель. Это общее число прочитанных книг в текущем сохранении, а не счётчик за календарный год.
- **☷ Настройки:** экспорт и импорт резервной копии. Импорт заменяет библиотеку после подтверждения.

На компьютере также работают стрелки влево/вправо; Escape закрывает карточку. Кнопки доступны без свайпов, предусмотрены подписи, фокус клавиатуры и уменьшение анимации по системной настройке.

## Каталог и обложки

Стартовая редакционная подборка содержит **11 произведений**, а не весь рынок русских переводов. Источники, переводчики, ISBN и дата проверки записаны в `data.js` и видны в каждой карточке и разделе «О каталоге». Для произведений из сборника ISBN относится к сборнику. Обложки — оригинальные графические оформления для приложения, а не фотографии изданий.

Правила расширения и проверки: [CATALOG.md](CATALOG.md). Наличие русскоязычного заголовка или `language: ru` в API не подтверждает издание. Автоматического импорта из внешних API нет. Все аннотации написаны отдельно и проверены по принципу «только исходная ситуация».

## Данные и офлайн

Библиотека хранится в `localStorage` под собственным ключом `pereplet:state:v1`. Учётной записи и серверной синхронизации нет. Сохранение зависит от браузера, профиля и адреса сайта; перенос с localhost на GitHub Pages требует экспорта/импорта. Не очищайте данные сайта без копии. Другие приложения на том же домене не используют наш ключ, но технически хранилище одного origin общее.

Приложение не содержит аналитики, внешних шрифтов, удалённых картинок или клиентских API-запросов. Внешние источники открываются только при нажатии на ссылку. Импорт принимает только известные ID и четыре допустимых статуса; HTML из файла не исполняется. При повреждённом сохранении запись блокируется, исходные данные можно скачать в настройках.

После первого успешного открытия через HTTPS или localhost service worker сохраняет интерфейс и весь каталог для офлайн-доступа. Дождитесь завершения первой загрузки перед отключением сети. Возможность добавления на главный экран зависит от браузера. При обновлении ресурсов увеличивайте `CACHE` в `sw.js`; новая версия активируется после закрытия старых вкладок.

## Локальный запуск

Требуется Node.js 22 или новее; установка пакетов и сборка не нужны.

```powershell
node server.mjs
```

Откройте `http://127.0.0.1:4173/pereplet/`. Остановка сервера — Ctrl+C. Не открывайте `index.html` двойным щелчком: ES-модулям нужен HTTP-сервер.

```powershell
node --test tests/*.test.js
```

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий, например `pereplet-books`. Для обычного бесплатного аккаунта используйте публичный репозиторий. Не загружайте личные резервные копии.
2. Загрузите содержимое этой папки в корень ветки `main`, включая скрытую папку `.github` и `.nojekyll`.
3. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В **Actions → Publish GitHub Pages** запустите **Run workflow**, если первая попытка до включения Pages завершилась ошибкой.
5. Дождитесь успешного выполнения; адрес покажет GitHub Pages. При имени `pereplet-books` ожидаемый адрес — `https://andybalkonsky.github.io/pereplet-books/` (до публикации это только ожидаемый адрес).

Workflow сначала запускает тесты, затем публикует только файлы приложения и `assets/`. Относительные пути позволяют использовать любое имя репозитория. Альтернатива без workflow: **Deploy from a branch → main → /(root)**.

Инструкция и версии Pages actions сверены с [официальной документацией GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) 5 ноября 2026 года.

## Состояние проверки этой поставки

- Пройдены 10 автоматических проверок: каталог, ISBN, решения и отмена, статусы/статистика, резервная копия, жанры, наличие ресурсов, установка офлайн-кэша, изоляция от других приложений и выдача ресурсов без сети в модели service worker.
- JavaScript проходит синтаксическую проверку Node.js.
- Локальный сервер запускается.
- Визуальный просмотр, реальные жесты, браузерное сохранение и service worker не проверены в браузере: доступ к локальному адресу был отклонён. Перед публичным запуском пройдите [CHECKLIST.md](CHECKLIST.md).
- Репозиторий: [andybalkonsky/pereplet-books](https://github.com/andybalkonsky/pereplet-books). Публикация запускается workflow **Publish GitHub Pages** при обновлении `main`; для первого запуска требуется **Settings → Pages → Source → GitHub Actions**. Результат публикации и адрес сайта доступны во вкладке Actions.

## Структура

`index.html` — оболочка; `app.js` — интерфейс; `core.js` — проверяемая логика; `data.js` — каталог; `style.css` — адаптивное оформление; `assets/` — локальные обложки/значки; `sw.js` — офлайн; `manifest.webmanifest` — установка; `.github/workflows/pages.yml` — проверка и публикация.

Для генерации обложек после изменения каталога: `node generate-assets.mjs`. Новые файлы также добавьте в `sw.js`, затем увеличьте версию кэша и запустите тесты.
